# 街區棋王 正式設計基線 — Redesign Spec Final（新遊戲 v0.1.0）

> 老闆拍板定案 12 條已鎖死。本 spec 是寫手 A（邏輯）與寫手 B（表現）的施工契約。
> 舊 kkpark-map（地圖版）封存不動；新遊戲目錄：**`web/kkpark-block/`**（短、中性、不撞名）。
> 版本從 **v0.1.0** 起算，行為改動必升 patch（沿用舊規則）。
> 中性代稱照舊：園區／巡查方／營運場所／線人。

---

## 0. 一段話

斜俯視 45 度街區動作放置遊戲：你的紙娃娃在 12–20 個不規則街區間自由走動，用據點與棋子跟巡查方搶地盤；據點裡是 Cookie Clicker 放置機；做壞事升 GTA 星星，星星等於巡查方怪潮；被捕擲 KCD 骰；跳槽後棋盤反轉、親手洗藍自己舊地盤。

---

## 1. 遊戲日迴圈：一天四段

| 段 | 時長 | 玩家在做什麼 | 系統在算什麼 |
|---|---|---|---|
| ①開機收帳 | 15–30s | 離線放置入帳面板＋**昨夜勢力戰報**（哪些街區易手、星星事件回放文字） | 離線收益（主動 1/8，上限 8h）＋暗件/口徑過期代價結算 |
| ②街上時光 | **3–4 分鐘（主玩法）** | 自由走動：跑單、談判、搬家當、踩點、據點互動 | 星星系統、巡邏班表、檢定 |
| ③處理帳面 | 30–60s | 收益分配滑桿：上繳（信任↑錢↓）／藏匿（錢↑識破風險↑）／再投資（升級） | 帳面自洽度微調 |
| ④睡覺世界結算 | 自動 5s 黑屏過場 | — | 勢力推拉引擎、巡邏重排、怪潮部署、存檔 |

設計錨：**一天一個 save 點（睡覺）**；街上中途離開＝不結算帳面（收益減半）——睡覺是節奏閥也是保險箱。

## 2. 勢力地圖（核心系統）

### 2.1 街區形狀（老闆明確要求）

- **不規則多邊形**：12–20 街區，波浪邊緣、非正方非正圓。
- 視覺基準：`web/kkpark-map/design/prototype/turf.html` **A 模式**——控制度 -100~100 顯示為色塊深淺＋中心數字。
- 生成規則（寫手 A）：**Voronoi 分割**——撒 12–20 個種子點（含 Poisson disk 最小間距），用種子抖動（jitter）產生不規則邊；邊界平滑一次（Chaikin）。種子固定 seed 存檔（同一存檔永遠同一張圖）。
- 每街區資料：`{id, polygon[], ctrl: -100..100, type: 營運/巡查哨/中立, yieldRate, gear}`。

### 2.2 控制度推拉引擎

```
每日結算（睡覺時）：
ctrl[blk] += parkPush - policePush + neighborFlow
parkPush   = 該街區綠方單位數×0.8 + 相鄰綠街區均ctrl×0.15 - 該區巡邏密度×k1
policePush = 巡查哨輻射強度（哨所在街區 3.0、相鄰 1.2，隨 S.police 進度 ×0.5~1.5）
neighborFlow = Σ(相鄰街區 ctrl 差 × 0.1)   ← 高地往低地滲
ctrl clamp ±100；±100 連續 3 天 → 街區「定色」（解鎖定色加成：綠=產出+25%，藍=巡查視野+25%）
```

玩家影響 ctrl 的主動手段：踩點（+8，冷卻）、交易成功（+5）、搬家當（+12，需檢定）、放置據點存在（每日 +3）、巡查方反制（夜間掃蕩 −15）。
**勢力地圖就是戰場 UI**：色塊深淺即時反映，不用打開任何選單。

### 2.3 巡查哨

初始 2 個哨所（地圖邊緣）；S.police 每進 25 階 → 增 1 哨（位置=控制度最低的藍傾向街區）。哨所可被玩家的「搬家當」行動拔除（高難度檢定+高成本）。

## 3. 走動與視角

- **自由走動**（方向鍵/WASD，八向），**斜俯視 45 度**。
- 渲染：sprite 四向（Kenney 包 `Man brown`/`Survivor` 系列），走路雙幀擺動＋方向翻轉；斜俯視=Kenney topdown 圖本來就是俯視，45 度感靠**建築物 y-offset 疊層**（下遮上）＋陰影方向統一 135°。
- 地圖滾動：相機跟隨主角（lerp 0.15），地圖尺寸 2.5–3 屏。
- 碰撞：街區多邊形可走；建築格子障礙（Kenney 地磚中有牆/樹）。

## 4. 星星系統（GTA 制 3 星）

| 星 | 進入條件 | 巡查方行為 | 降星條件 |
|---|---|---|---|
| 0 | — | 班表巡邏，不主動追 | — |
| 1 | 被目擊交易（視線 140m 內有巡查單位＋機率 0.35）、盤查後逃跑 | 附近 1–2 單位轉追擊 | 脫離視線 40s |
| 2 | 1 星下再犯（30s 內）、或被盤查檢定大失敗 | 追擊單位 3–4＋**怪潮預備**（地圖邊緣集結，80s 後湧入） | 脫離視線 60s＋距離 400m |
| 3 | 攻擊巡查單位、拔哨所失敗被目擊 | **倖存者式怪潮**全開：邊緣連續增援 3 波，玩家自動技能開火清路 | 唯一出口：脫離地圖（躲回據點）或被捕 |

- 追擊 AI（寫手 A）：追擊單位用 A* 沿可走格追（每 0.5s 重算）；脫離視線（120m＋障礙遮蔽）計時降星。
- **自動技能**（玩家裝備解鎖，星星時自動觸發）：誘餌（生成假目標 5s）／煙霧（半徑 150m 視線遮蔽 8s）／機器人分身（吸引火力 10s）。冷卻各 30s，消耗放置產出資源——**放置產出餵動作技能**，兩系統互餵的關鍵掛點。
- 怪潮單位＝`Zombie` 系 sprite 重著色（深藍制服）——潮怪備案照老闆清單。

## 5. 被捕：KCD 式檢定

被捕瞬間進檢定畫面（三選一連續擲）：

```
身手線：身手 vs 巡查強度(10+2×星) → 成功掙脫（星星歸零回到街角，收益不損）
賄賂線：花 30% 現金 + 膽識檢定 → 成功放行（錢損、無拘留）
求情線：口才檢定（難度高）→ 成功警告釋放；失敗則…
失敗後果（老闆拍板）：扣錢 20% ＋ 拘留一回合（隔天開機才出來，當天街上時光損失）
拘留中彩蛋：獄中遇到老部下/巡查探員——跳槽線的祕密入口之一
```

檢定公式（全遊戲統一）：`d20 + 屬性 + 裝備修正 vs 難度(10~20)`；大成功（nat 20）雙倍效果、大失敗（nat 1）加壞後果。屬性見 §6。

## 6. 屬性與成長（檢定滲透的燃料）

四屬性：**口才／身手／頭腦／膽識**。

- 成長管道三條：①**修練點擊**（據點內 Cookie Clicker：點擊產「經驗粒」，選屬性灌注——手動點擊×10 效率）②派遣小弟跑單成功回饋小經驗③檢定成功該屬性 +1 經驗（用中學）。
- 成長曲線：等級需求 `next = 15 × lvl^1.5`；lv1 起，首週到 lv3–4（30 分鐘第一次有感升級＝第一次灌注滿一級）。
- 檢定滲透清單（寫手 A 對照表）：談判(口才)、搬家當(身手+頭腦)、求情(口才)、被盤查逃跑(身手)、圓謊(頭腦)、上繳分配談判(膽識)、跳槽攤牌(膽識+口才)。

## 7. 據點與放置（Cookie Clicker 層）

- 據點=街區地圖上的**一格**：走進切**內部視角**（全屏切換，Kenney 室內磚）。
- 內部功能：**點擊產出機**（主按鈕：每點 +1 貨，貨→錢匯率隨升級）、**雇小弟**（自動產出者，`Man/Survivor` sprite 站崗動畫——看得見的機器）、升級櫃（產出×2 鏈、離線時長、自動技能槽）。
- 離線收益＝主動的 **1/8**，上限 8h；回來先收拾（暗件佇列/口徑過期式代價，沿用 redesign-brief-idle §1–2 的設計，敘事改「小弟囤了事等你回來裁決」）。
- 據點可升級為分點（一個據點→多個）：第 2 個據點解鎖於第 3 天（擴張的放置深度）。

## 8. 跳槽系統（勢力投誠制）

- 觸發：S.police ≥ 60 或獄中密談事件 → 巡查方密使來訪（檢定會議）。
- **接受後棋盤反轉**：所有綠色街區變成你的任務目標（親手洗藍：踩點改「掃蕩」、舊據點要逐個「查封」）。
- 星星反轉：你現在**帶巡查方潮**（怪潮變成你的武器，召喚冷卻制）；你自己有「舊關係懷疑度」條（被舊組織盯上）。
- 老部下求情：查封舊據點時紙娃娃 NPC 到場（檢定放水＝頭腦檢定）——放水＝查封進度慢、不放＝後期遭遇戰更難。**前期放置的每一格都是後期劇情彈藥**（v4 承諾兌現）。
- 跳槽不改地圖不改引擎：只翻轉陣營參數表（哪邊是「你方」、星星誰帶誰）——工程上是一個 `faction` 旗標。

### 9.1 美術統一規格（沿用 art-bible 精神，街區版）

- **色板**：墨層 `--bg #0b0e14` 不變；街區色塊——綠方 `#4dff9d` 透明度階梯 0.08→0.45（八階=控制度八檔）、巡查方 `#5aa7ff` 同階梯；星星紅 `#ff4d6d`；金錢金 `#ffe14d`。**街區色塊永遠半透明疊在磚上，磚色不變**——勢力是「光」不是「漆」。
- **比例**：角色 32px 高（Kenney 原生）、磚 32×32、建築格 64×64；相機 zoom 固定 2×（像素 perfect：`image-rendering: pixelated`）。
- **字**：數字 UI 用 Cubic 11（像素繁中），正文 Noto Sans TC（照 art-bible §3）。
- **圖示**：沿用 game-icons.net 單色 SVG 制（art-bible §4），emoji 禁令照舊。
- **光**：日夜四段窗光/路燈=半透明黃暈疊層（v3 遺產，v0.2 再上，本版只做色塊）。

## 10. 技術決策

- **引擎：PixiJS**（寫手 B 評估過純 Canvas，但怪潮 30+ 單位＋色塊多邊形＋粒子，PixiJS 的 DisplayObject 樹省大量自製輪子；CDN 單引入，無建置流程）。
- GitHub Pages 靜態交付、無建置工具、單檔 ≤500 行照舊。
- 檔案結構（≤500 行/檔）：`index.html / style.css / main.js / map.js（Voronoi+渲染）/ walk.js（主角+相機+碰撞）/ star.js（星星+追擊 AI+怪潮）/ dice.js（檢定）/ base.js（據點+放置）/ faction.js（勢力引擎+跳槽）/ save.js / audio.js（tone() 遷移）`。
- 存檔：localStorage，`S = {day, money, ctrlMap, stars, attrs, bases, faction, seed, …}`；**seed 固定地圖**。

## 12. 垂直切片（兩週內給老闆摸操作感）

**切片範圍＝①＋②＋③中的粗體核心：8 街區小圖（12 的子集）＋自由走動＋1 次交易檢定＋升 1 星→被追→自動技能脫身＋一個據點點擊機＋睡覺結算（色塊流動一次）。**

兩週里程碑：D1-3 地圖+走路（A1∥B8）；D4-6 色塊+檢定（A2-A3∥B9）；D7-9 星星+追擊（A4∥B11）；D10-12 據點點擊+日結（A5-A7∥B10）；D13-14 接縫+拋光。

驗收問句（老闆親測）：**「在路上被追的時候，你會不會下意識想按方向鍵跑？」**——身體在場＋星星壓力的第一手檢定。
