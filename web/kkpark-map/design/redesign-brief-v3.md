# 沉浸感層 — Redesign Brief v3

> 老闆第三輪回饋：「很沒有帶入感。我想像 Kingdom Come: Deliverance 一樣，有很深的遊戲沉浸感。」
> 本 brief 只做一件事：把 v2 的六系統**搬進一個房間**。系統清單不動（v2 是骨架，v3 是血肉），改的是每個系統「長在哪、長成什麼、手感是什麼」。
> KCD 五味拆解：①身體在場 ②實體操作 minigame ③人是人 ④介面擬真化（diegetic，HUD 極少）⑤氛圍（日夜、音效、後果會留下）。

---

## 0. 總原則：房間是唯一的 UI

玩家永遠坐在同一張桌子前。螢幕上**沒有面板、沒有按鈕列、沒有 tab**——只有桌面、桌上的東西、兩台螢幕、一扇窗、一部電話。所有 v2 系統變成桌上的實物；所有操作變成手部 minigame；所有資訊長在世界物件上（便條的字跡歪斜＝規則寫得急、帳冊的墨色＝哪本動過手腳）。

**沉浸感的第一定律：資訊不會跳出來找你，是你在房間裡找到它。**（唯一例外：電話鈴聲——那是世界內的聲音，不是 HUD。）

## 1. 六系統 diegetic 化對照表

| v2 系統 | 長在世界裡的位置 | 長成什麼 | 資訊怎麼呈現 |
|---|---|---|---|
| 規則引擎（腳本槽） | 右螢幕旁的**軟木板＋便條牆** | 一張便條＝一條 IF-THEN（「附件缺→扣留」是手寫字，不是代碼）；拖便條排序＝腳本優先級；撕掉＝刪規則 | 便條紙色（新規則亮黃→舊規則茶漬）；字跡抖動度＝規則複雜度；**複核炸彈**（寫錯的規則）在便條背面洇出紅暈——翻面才看得到 |
| 裝備欄 | **桌面實體擺設**（左下區） | 碎紙機、假章罐、電話、咖啡杯、第二螢幕——像素畫擺在桌上，有影子 | 裝備狀態長在實物上：碎紙機滿了露出紙屑、咖啡見底＝冷卻中、假章罐蓋子沒蓋＝最近用過 |
| 三本帳 | **桌右側的書堆** | 三本實體帳冊（真帳深棕、園區帳紅、巡查帳藍），點開=翻頁 UI（頁面是帳目表格，但紙質、摺角、墨跡） | 自洽度不顯示數字——**帳冊頁緣的陰影越深＝越接近爆點**；被審計抽中的科目會有摺角痕 |
| 暗件佇列 | **桌左側的紅線紙疊** | 用紅繩綑住的一疊紙，每來一件「啪」一聲丟上來（紙堆物理性長高）；每張紙上有封蠟/綁法差異＝來源不同 | 堆疊高度就是佇列深度（超過 20 張會滑落——溢出前兆）；最上面那張永遠是最新件 |
| 營運網格（左帳） | **左螢幕**（螢幕內容） | 螢幕裡是園區管理後台的像素 UI（這層允許「螢幕中的螢幕」——數字、圖表在 CRT 掃描線裡滾） | 離線收益、場所狀態全在左螢幕裡——**放置層被隔絕在螢幕內，房間保持擬真** |
| 檔案流（右帳） | **右螢幕＋桌面文件架** | 例行檔案從右螢幕「印出來」滑到文件架（或直接螢幕內處理——見 §4 抉擇）；處理過的檔案實體堆在右下角 | 已處理堆的高度＝今天的工作量（成就的實體化）；抽查通知是**傳真機吐紙**（世界內事件） |
| 跨帳操作 | 桌中間的**黑皮包** | 打開皮包＝跨帳轉移介面（把鈔票/卡片從左側格子挪到右側格子的實體動作） | 手續費＝皮包內襯磨損度視覺；轉移中電話更容易響（風險的世界內提示） |

## 2. 實體操作 minigame 目錄（KCD 開鎖的對應物）

每個 minigame 三要素：**手在做什么／手感（輸入曲線）／失敗後果**。全部 DOM+CSS transform 可做。

| Minigame | 操作 | 手感設計 | 失敗後果 |
|---|---|---|---|
| **蓋章** | 按住蓄力（0.3–0.7s 綠區）放開落下 | 力道條隱藏——用印章影子大小＋按壓阻尼暗示；「咚」聲（tone 低頻短音）＋紙面微震 | 太輕＝章印模糊（複核可爭議＋）；太重＝印油暈開（該件標記可疑） |
| **偽造簽名** | 在半透明範本上描字跡（滑鼠/觸控路徑 vs 目標路徑偏差） | KCD 開鎖的直系血緣：範本 3 秒後淡出＝靠記憶描；抖動回饋即時（筆跡跟著抖） | 偏差超界＝簽名被退（該件重做＋時間損失）；連續失敗 3 次＝這支筆「不行」換筆（隨機新曲線） |
| **碎紙** | 按住餵紙（紙張一格一格吞入＋馬達聲） | 餵太快卡紙（要反向抖動救援）；聲音隨紙量悶→空轉 | 卡紙＝碎紙機過熱冷卻 30 秒（暗件處理停擺——壓力的實體化） |
| **數鈔** | 快速交替點擊/滑動數鈔，數錯要重數 | 節奏類音感：數對有遞增音階；鈔票飛走動畫 | 數錯＝帳面差額（三本帳多一筆要平的錢——minigame 失敗接回系統層） |
| **對暗號** | 電話對話中的節奏回覆（NPC 說上半句，玩家在拍點內點下半句） | 節奏遊戲判定（Perfect/Good/Miss）；暗號內容是文案，拍點是玩法 | Miss＝對方起疑（該線人信任 −，連續 Miss＝斷線） |
| **調頻竊聽** | 旋鈕拖曳找頻段（噪聲中浮出人聲的模糊帶） | 噪聲用 WebAudio 白噪＋濾波掃頻；人聲浮現用清晰度漸變；找到後要「保持」3 秒 | 頻段每天換（重生內容）；被反偵測＝識破度小漲 |

**通用手感鐵律**：每個 minigame ≤8 秒；失敗永遠有 2 秒內的視覺+觸覺（震動/聲音）回饋；失敗後果**全部接到系統層**（帳、識破度、信任）——手感遊戲不是派對，是這個世界的物理。

## 3. 人層：來訪者、電話、讀人

- **來訪（紙娃娃本命時刻）**：有人約見＝**門口有影子**（門縫下透光＋腳步聲預告），點門＝對方**坐到你桌子對面**——紙娃娃頭像（有臉！maplestory API 現成）坐在畫面對面區域，有對白樹。**讀人**＝觀察細節：今天穿的顏色（情緒）、坐姿（緊張/放鬆）、說話時的道具（他帶了東西來）——這些是對話選項的前置情報（觀察錯＝選項解鎖錯）。
- **電話**：實體電話在桌左下。響鈴用 tone() 合成（鈴聲音色隨來電方微調——聽音辨人，高級資訊長在聲音裡）；**會漏接**：忙於 minigame 沒接＝留言紙條從電話底下吐出（紅色燈亮）。漏接的後果照 idle 增補「線在冷」——但現在它是實體燈與紙條，不是 HUD 通知。
- **NPC 記憶（KCD 第③味）**：每個來訪者有自己的記憶卡（藏在對面坐姿底下——桌面上看不見，玩家要在對話中拼出）：你上次說過什麼、上次答應什麼。**口徑賬本（v2 遺產）變成桌下壓著的一疊自己的舊便條**——翻自己的字跡來圓謊。

## 4. 走動世界層：推薦「固定房間＋窗景」，Leaflet 降級為**接頭地圖**

抉擇分析：

| 方案 | 得 | 失 |
|---|---|---|
| A. Leaflet 大地圖當身體層（保留走動） | 身體在場（KCD①）、回收前版資產 | 沉浸感斷裂：桌上 minigame 的「手」與地圖的「腳」是兩個遊戲；HUD 會復活（地圖必需縮放/圖層 UI） |
| B. 第一人稱固定場景（只有桌面與房間） | 沉浸感最大化、工作量最小、minigame 全部同屏 | 「世界」只剩房間——園區的存在感全靠螢幕與電話轉述，身體在場弱 |

**推薦：B 為主體＋Leaflet 降級為「接頭地圖道具」**——房間抽屜裡有一張**真實城市地圖（Leaflet 深色瓦片，現成資產）**：接頭/押送/查哨前攤開它（世界內道具，全螢幕翻開但保持紙質濾鏡與手電筒光圈），在上面規劃路線、標記巡查哨點、看今天哪條街危險（heat 的地理化）。規劃完收起地圖，**人還是坐在桌前**——「走到哪」被敘事為「你的人去了」（左螢幕派遣面板＋電話回報），玩家用規劃與裝備決定成敗，不用親自走路。

這樣 KCD①（身體在場）由「你有房間、有手、有腳步聲的來訪者」承擔，KCD④（diegetic）不被地圖 HUD 破壞，Leaflet 資產也沒浪費——**地圖從世界縮成道具，反而更貼「情報工作在桌前完成」的題材真相**。

## 5. 節奏調和：KCD 慢 vs idle 快

- **分層節奏**：左螢幕（園區端）＝idle 快節奏（數字滾、暗件堆——Candy）＋房間（右帳端）＝KCD 慢節奏（minigame、來訪、翻帳——Meat）。快慢不是矛盾，是**手與眼的分工**：掃左螢幕 5 秒、回桌面 30 秒。
- **離線＝世界繼續動的敘事包裝**：回來時房間有「你不在時的痕跡」——咖啡涸了（杯底殘渣）、文件架堆高了、電話底下塞了三張留言、**窗外天色變了**（日夜循環跟離線時長同步：掛 8 小時回來窗外是月亮）。**離線收益不用「+xx」toast，是房間狀態的讀取**。
- **音效節拍**：房間底噪（時鐘滴答+遠處雨/車流——tone() 合成持續低音）＋事件聲（檔案印出、暗件拍上、電話鈴）。安靜不是無聲，是底噪——KCD 氛圍第⑤味的最低成本實作。
- **後果會留下**：KCD⑤——被複核抓過的帳冊頁有紅筆痕不消失、碎紙機卡過紙就永遠有個貼條、斷線的線人號碼在電話本上被劃掉。**房間是玩家的履歷，不是每次刷新重置的介面。**

## 6. 純 DOM/CSS/WebAudio 可行性

| 挑戰 | 解法 | 工作量 |
|---|---|---|
| 印章/描字跡/碎紙/數鈔 | DOM 元素＋CSS transform＋pointer events（無 canvas 依賴；描字跡用 SVG path 記錄比對） | 每 minigame 0.5–1 人日，共 3–5 |
| 房間場景 | 單一 HTML 結構（桌面/窗/門/兩螢幕/擺設），CSS 光影（窗光角度隨日夜旋轉——色溫 CSS 變數，照 art-bible §2 語義色票） | 2–3 人日（首版） |
| 臉 | 紙娃娃 API（maplestory.io，現成＋快取法照 kkpark-verify 前置）或 SVG 頭像 | 0.5 人日 |
| 音效 | tone() 合成器擴充（鈴聲/馬達/紙聲=短噪聲包絡/底噪=濾波白噪循環）——零音檔 | 1 人日 |
| 日夜窗光 | CSS filter + 色溫變數 + 天色漸層（與離線時長同步） | 0.5 人日 |
| **總計**（v2 骨架外的沉浸層增量） | | **7–10 人日** |

單檔 ≤500 行限制下：房間場景與 minigame 各自拆檔（room.js / minigames.js / audio.js——audio 從 kkpark-game 借 tone() 起家）。

## 7. 給 v3 沉浸探針的驗證面（指揮官驗感覺用）

1. **手的第一秒**：拖起一疊紙——紙堆有重量感（拖曳慣性+散開動畫）？蓋下第一個章——「咚」聲＋紙面震動？
2. **房間呼吸**：窗光色溫 30 秒內可感知變化？底噪存在但不搶戲？
3. **人在對面**：來訪者坐下時，玩家**先注意到臉還是先注意到 HUD**？（探針測法：藏掉所有非 diegetic 元素，看玩家能不能完成「收一件暗件+蓋一個章+接一通電話」）
4. **漏接的痛**：故意不接電話 60 秒——紅燈與留言紙條是否足以讓玩家「意識到自己錯過了什麼」，而不需要任何彈窗？

三者過二＋第四條過 → 沉浸層方向成立。
