# 美術聖經 — 園區地圖（Art Bible v1）

> 守門文件：所有表現層改動（style.css / ui.js / map.js / dock.js）以此為準。
> 審核問句只有一句：「這個元素在這三層裡守好自己的位置了嗎？」

---

## 0. 語氣定調

**夜城霓虹 × 電子儀表 × 像素溫度。**

- 世界是入夜後的港區城市：冷、暗、被霓虹點亮。畫面底層永遠是暗的，光是有來源的。
- UI 是監看儀表：深色面板、1px 邊框、資訊密度克制，像操作台的儀器而不是網頁卡片。
- 人物是畫面上唯一的暖色像素（紙娃娃）。眼睛一秒找到「人」，因為人是唯一的例外。

一句話給所有取捨投票：**「這是夜裡的一台監看器，器上有一個活人。」**

## 1. 三層視覺（對應櫻井 030「判定物強調、非判定退後」）

| 層 | 內容 | 規則 |
|---|---|---|
| **L0 舞台** | 地圖瓦片 | 去飽和、無標籤搶戲；路網可讀但低調。瓦片是布景，不是主角。 |
| **L1 儀表** | HUD、面板、marker pill、dock | 深底＋1px 邊框＋圓角。**glow（光暈）只給「活著的」元素**：進行中任務、警報、低資源警告。靜態元素不准發光。 |
| **L2 溫度** | 紙娃娃、主角光環 | 像素渲染（`image-rendering: pixelated`）不可破壞；是畫面唯一多彩處。其他層若想加彩色，先問：會不會搶走「找人到一秒內」？ |

光有來源（櫻井 010「畫光不畫素材」）：每個 glow 必須答得出光源是什麼——警燈（紅藍交替）、霓虹招牌（青粉）、主角光環（金）、儀器指示燈（綠）。答不出的 glow 不做。

## 2. 色票（CSS 變數，語義制）

現行 12 變數是隨手配；改為語義分組。**代碼裡不準出現裸 hex**（瓦片濾鏡與 Discord 品牌色除外），一律引用變數。

```css
:root {
  /* 墨層（L0/L1 底） */
  --bg:      #0b0e14;  /* 舞台最深底 */
  --panel:   #121722;  /* 面板底 */
  --panel2:  #1a2130;  /* 面板內層次 */
  --line:    #2a3348;  /* 1px 邊框／分隔 */

  /* 字層 */
  --txt:     #e8f0ff;  /* 正文 */
  --dim:     #8b97b0;  /* 次要 */
  --faint:   #5a6580;  /* 三級／腳註（新） */

  /* 語義色（全遊戲同螢幕可見 ≤4 種） */
  --ok:      #4dff9d;  /* 成功／待命／完工 */
  --warn:    #ffe14d;  /* 金錢／資源緊／提醒 */
  --danger:  #ff4d6d;  /* 警戒／損失／查崗 */
  --info:    #5aa7ff;  /* 警方／資訊 */

  /* 品牌霓虹（只給「活著的」元素） */
  --neon:    #7df9ff;  /* 主青：進行中、可互動 */
  --neon2:   #ff5ec4;  /* 主粉：組織本體（HQ、名冊標題） */
}
```

用色三規：

1. **glow 只有一層**：文字、邊框、box-shadow 三層同時發光是禁手；至多邊框＋陰影一層光。
2. **金 = 錢、紅 = 危、青 = 活、粉 = 家**。語義漂移（例如拿金色標無關的強調）退回。
3. 漸變只用兩處已授權：條形圖填充（`linear-gradient` 語義色）、heat 計（金→紅）。其他地方漸變要提案。

## 3. 字體

| 用途 | 字體 | 備註 |
|---|---|---|
| 正文 UI | Noto Sans TC（現行） | 不動 |
| **數字／金額／時間戳／版本號** | **Cubic 11**（開源繁中像素字體，SIL OFL，可自host woff2） | HUD 的 `$60,000`、`第 1 天 09:12`、`v0.5.x` 改像素數字——與紙娃娃同血統，遊戲感立刻成立；正文不換，可讀性優先（櫻井 033） |
| fallback | Microsoft JhengHei → sans-serif | 保留 |

尺寸階梯固定四級：`11 / 12.5 / 14 / 20px`，不新增級距。標題字距 `letter-spacing: 1px` 起跳。

## 4. 圖示風格

- **主套件：game-icons.net**（單色 silhouette，CC BY 3.0，4000+ 張，遊戲語彙最全）。
- 呈現：`fill: currentColor` 單色上色，跟語義色走；尺寸 14/16/20px 三檔。
- 對照表與退役計畫見 [emoji-retirement.md](emoji-retirement.md)。
- 套件缺的在語彙（夜市攤、宮廟等在地物）**自製 SVG 補**，規格同套件：單一 path、16 viewBox、無漸變無內嵌色。
- 禁 emoji 當圖示。對話/文案裡的表情符號（🙂😅 段落語氣）**不在此限**——那是文字不是圖示（櫻井 093 漫畫表現背書）。

## 5. Juice 規格（震動／粒子／音效觸發時機）

原則（櫻井 effects.md 103 + sound.md 032）：音效優先序按「對玩家影響度」排，不按音量排；震動分大小檔且震法不同；全部短促（≤0.5s）、起始強、收斂快。

### 音效優先序（大→小）

| # | 事件 | 音 | 實作 |
|---|---|---|---|
| 1 | 逮捕／攻堅結算（勝敗級） | 低沉判定音，成敗各一 | tone() 合成 |
| 2 | 查崗倒數（heat 91 主動查崗） | 心跳式短敲，頻率隨倒數升高 | tone() |
| 3 | 收錢／結帳（核心回饋） | 短「叮」＋金額跳動 | tone() |
| 4 | 任務完成／派遣出發 | 中性確認音 | tone() |
| 5 | 按鈕點擊 | 極短 tick | tone() |
| 6 | 環境（雨、遠處車流） | 低音量循環，可靜音 | 後期 |

合成器現成：`web/kkpark-game/audio.js` 的 `tone()`——抽共用或複製，**不引外部音檔**（零資產依賴是本專案優勢）。環境音優先度最低，不准蓋過 3 以上（櫻井 202）。

### 螢幕震動（三檔，震法不同——不是縮放差）

| 檔 | 事件 | 震法 | 時長 |
|---|---|---|---|
| 小 | 查崗倒數 tick | 縱向 1-2px 微顫 | 0.12s |
| 中 | 查崗爆發／攻堅開始 | 縱＋橫 3px，初強收斂 | 0.35s |
| 大 | 逮捕／破產結算 | 縱＋橫 5px＋角度微旋 | 0.5s |

掛 `body` 或 `#map` 容器 transform，不動 Leaflet 內部座標。連續事件取最大檔不疊加。

### 粒子（DOM/CSS 即可，不上 canvas）

| 事件 | 表現 |
|---|---|
| 收錢 | 金色浮動數字（現有 `.num-jump` 升級：數字＋微光粒 2-3 顆上飄） |
| 建築完工 | 綠色 ring 從 marker 外擴一次（`scale + fade`） |
| 逮捕 | 紅色 burst 6-8 顆＋heat vignette 瞬間拉滿再回 |
| 派遣小人出發 | 腳下塵埃 1-2 顆灰粒 |

粒子規則：同時在畫面 ≤12 顆、壽命 ≤0.8s、位置錯開不重疊（櫻井 242 負荷原則）。

### 閃光

白閃禁大面積。需要閃時用「暗色穿插」明暗交替（櫻井 221：純白在亮畫面看不到、也防光敏），頻率 ≤3 次/秒。

## 6. 禁止清單（審核速查）

1. ❌ 新增 emoji 當圖示（圖示管線已定，走 SVG）
2. ❌ 三層 glow 疊加、無光源的 glow
3. ❌ 裸 hex 出現在 style.css / JS 字串（變數制）
4. ❌ 動畫週期 >1.6s 的常駐 glow（現在的 misGlow 2.4s 要收）
5. ❌ 大面積純白閃光
6. ❌ 互動元素與裝飾元素對比度倒置（裝飾比按鈕還搶眼）
7. ❌ 瓦片上蓋任何不透明 UI（HUD 漸層淡出是上限）
