# Design Reference Sources

## `VoltAgent/awesome-design-md`

用途:

- 參考不同產品的視覺語氣與品牌風格
- 快速取得可給 AI agent 使用的 DESIGN.md 範例
- 作為 UI 生成時的設計方向資料庫

## 值得注意的內容

- 這是一個 curated collection，整理多個公開網站的 DESIGN.md
- 每份 DESIGN.md 通常包含視覺主題、色彩角色、字型規則、元件樣式、版面原則、層次深度、Do/Don't、響應式行為與 prompt guide
- 適合用來定義頁面風格，而不是直接當成程式邏輯規範

## 使用原則

- 在需要調整 UI 方向、頁面氣質、字體與色彩系統時優先參考
- 若要落地到 kkgroup，先挑選符合產品調性的單一風格，再轉成專案自己的設計規範
- 不要直接照抄品牌識別或專屬資產，僅取可重用的設計結構與表達方式
